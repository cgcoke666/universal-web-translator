翻译引擎

默认先走 Chrome 内置翻译（端上运行，完全免费、文本不出设备）， 失败或语言不支持时再依次尝试下面的远端通道（Microsoft/Edge → Google）。 填写 Key 后可获得更高质量或本地大模型推理。

Chrome 内置翻译（端上 / 离线）

使用 Chrome 138+ 自带的翻译模型：完全免费、无需 Key、文本不出设备。 首次翻译某个语言时会自动下载一个小语言包（几 MB）。此项始终优先于下面的远端引擎， 不可用时自动降级，不会影响翻译结果。

关于

  • 快捷键：Alt+Shift+T 翻译/还原页面；Alt+Shift+M 切换显示模式。
  • 隐私：默认使用 Chrome 内置翻译，文本不离开本机；只有降级到远端引擎时，被翻译的文本才会发送给该引擎。API Key 保存在浏览器本地存储中。
  • 内置翻译说明：需要 Chrome 138+ 桌面版。首次翻译某个语言时会下载一个小语言包（几 MB），之后可离线使用。它由页面上下文执行（需要用户手势），失败会自动降级，不影响翻译结果。
  • 免费通道说明：Microsoft/Edge 与 Google 通道使用其公开 Web 服务，无需 Key，但存在配额限制，请勿用于高频批量场景。
